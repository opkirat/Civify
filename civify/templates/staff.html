How sentences are sorted

Ready: the quote was found in the report, every number matches, a second AI check found the quote fully supports the sentence, and the sentence doesn't state a decision, condition, uncertainty or deadline. Publish these together.

Needs a look: any of those checks raised something. The reasons are listed on each one. Code cannot judge meaning, and the AI check can be wrong, so you decide.

Blocked: the quote wasn't found or a number doesn't match. It can't be approved as written: edit it so it passes, or reject it.
